CAR PHOTOS
==========

Save a photo of each car model in THIS folder with exactly the file name below
(.jpg, .jpeg, .png or .webp). Restart the site (F5): the photo replaces
the illustration on Car rental and My Bookings.

Cars you add in Admin > Car Rental work the same way: model name in lower case,
spaces replaced with '-' (e.g. "Toyota Camry" -> toyota-camry.jpg).

Free photos: unsplash.com, pexels.com, commons.wikimedia.org

Tip: a side or 3/4 view on a plain background looks best (landscape, ~1200 x 800).
